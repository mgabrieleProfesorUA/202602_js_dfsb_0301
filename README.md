# Proyecto de Caso de Negocio: "Sistema de Gestión de Reservas para Coworking"
El proyecto presenta la funcionalidad del registro de reservas de salas para coworking y se divide en:

## Gestionar Salas de Reuniones
Esta funcioanlidad nos permite crear, actulizar y dar de baja las Salas de Reuniones

## Gestionar Usuario
Esta funcioanlidad nos permite crear, actulizar y dar de baja a los Usuarios del sistema.
